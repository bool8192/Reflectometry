# Конвейер ML-анализа рефлектометрии

Высокопроизводительный ML-ориентированный фреймворк для решения обратных задач рассеяния в нейтронной и рентгеновской рефлектометрии. Система заменяет традиционные методы подгонки надёжным оптимизационным конвейером, использующим **PyTorch**, **байесовский вывод** и **свёрточные нейронные сети (CNN)**.

## Основные возможности

*   **Высокопроизводительные вычисления**: Полная векторизация с использованием PyTorch, позволяющая масштабируемый анализ сложных многослойных систем (900+ параметров).
*   **Продвинутое моделирование шероховатости**: Реализация профилей интерфейсов на основе полиномов Бернштейна, обеспечивающая значительно большую гибкость по сравнению со стандартными моделями на базе функции ошибок (erf).
*   **Гибридная стратегия оптимизации**: Многостадийный конвейер, сочетающий **AdamW** для градиентного спуска, **дифференциальную эволюцию (Differential Evolution, DE)** для глобального поиска и **MCMC (Метрополис-Гастингс)** для анализа апостериорного распределения.
*   **Динамическое разрешение**: Адаптивный расчёт сетки и моделирование инструментального разрешения (dq/q = f(q)) с помощью оптимизированных модулей свёртки.
*   **Функции потерь с усилением CNN**: Интеграция 1D-CNN-преобразований непосредственно в целевую функцию для извлечения структурных признаков и повышения стабильности сходимости на данных высокого разрешения.

## Структура проекта

Репозиторий организован вокруг двух основных подходов к моделированию:
1.  **Классическая подгонка**: Прямая оптимизация структурных параметров.
2.  **Параметризованная подгонка**: Структурные параметры задаются параметрической моделью, в функциях ошибок применяется CNN, для экспериментальных данных высокого разрешения.

### Основные модули

*   `variables.py`: Конфигурация физических констант, границ оптимизации и гиперпараметров.
*   `add_roughness.py`: Генерация непрерывных профилей плотности длины рассеяния (SLD) из дискретных описаний слоёв с использованием полиномов Бернштейна.
*   `calculating_dynamic_resolution.py`: Основной физический движок для симуляции кривых рефлективности с адаптивной дискретизацией.
*   `convolution.py`: Моделирование инструментального разрешения с помощью свёртки с гауссовым ядром.
*   `objective_function.py`: Библиотека пользовательских функций потерь, включая многоуровневый взвешенный MSE и сопоставление признаков на основе CNN.
*   `optimizer.py`: Оркестрация гибридных процедур оптимизации (AdamW + DE) на базе разных функций потерь.
*   `ref.py`: Объединение всех расчётов прямой задачи рефлектометрии с учётом всех параметров установки в одну функцию.
*   `plotting.py`: Набор инструментов визуализации для кривых рефлективности, профилей SLD.
*   `fitting.ipynb`: Основной модуль, из которого применяются все остальные + работа с MCMC, репрезентация статистического ансамбля.

## Формат данных

Начальные приближения задаются в файле `readme.txt` (или аналогичных входных файлах) по следующей схеме для каждого слоя:  
`[Толщина] [SLD] [Ширина шероховатости] [Коэффициент_Бернштейна_1] [Коэффициент_Бернштейна_2] [Коэффициент_Бернштейна_3]`

## Производительность по сравнению с отраслевыми стандартами

Данная реализация демонстрирует значительные преимущества перед стандартными инструментами, такими как **GenX** или **MOTOFIT**:

*   **Сходимость**: Стабильная сходимость даже из далёких начальных приближений благодаря многоуровневым ландшафтам потерь.
*   **Масштабируемость**: Линейная сложность по сравнению с квадратичной в стандартных решениях, что позволяет проводить подгонку систем с 900+ параметрами.
*   **Квантификация неопределённостей**: Предоставляет полные статистические распределения и корреляции параметров вместо простых точечных оценок.
